# Ticket Designs

This directory contains custom ticket background images for scratch tickets.

## BASIC Ticket Image

The basic-ticket.png image should show:
- Top left banner: "GRATE TOUTE" on brown/maroon banner
- Top right badge: "50 GOURDES" on gold/orange badge
- Main logo: Large "GRATE GENYEN" text (yellow and light blue 3D effect)
- Category ribbon: White/silver banner with "Basic" in gold text
- Scratch area: White rectangular box in the center (this is where scratch overlay goes)
- Bottom label: "BASIC" text
- Bottom banner: "5,000 GOURDES!" on gold banner
- Background: Green sparkly texture with star/sparkle effects

The scratch overlay will be positioned over the white rectangular scratch area using CSS positioning.
