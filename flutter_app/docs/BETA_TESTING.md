# Beta Testing Guide

## Overview

Welcome to the Grate Genyen beta testing program! This guide will help you participate in testing our raffle ticket management app.

## Getting Started

### Prerequisites
- Android device (Android 7.0+) or iOS device (iOS 12.0+)
- Active internet connection
- Valid phone number for registration

### Installation

#### Android (via Firebase App Distribution)
1. Check your email for the Firebase App Distribution invitation
2. Click the invitation link
3. Install the Firebase App Distribution app if prompted
4. Download and install Grate Genyen beta app
5. Trust the app in your device settings if needed

#### iOS (via TestFlight)
1. Install TestFlight from the App Store
2. Check your email for the TestFlight invitation
3. Click "View in TestFlight" or open the link
4. Accept the invitation
5. Install the Grate Genyen beta app

### First Launch
1. Open the app
2. Grant necessary permissions (camera, storage, notifications)
3. Create an account or login
4. Explore the app features

## How to Provide Feedback

### Bug Reports
When you find a bug, please include:
1. **Description**: What happened?
2. **Steps to Reproduce**: How can we recreate it?
3. **Expected Behavior**: What should have happened?
4. **Actual Behavior**: What actually happened?
5. **Screenshots**: If applicable
6. **Device Info**: Model, OS version
7. **App Version**: Found in Settings > About

### Feature Feedback
Share your thoughts on:
- What features you love
- What could be improved
- Missing functionality
- Suggestions for enhancements

### Reporting Methods

#### 1. In-App Feedback (Preferred)
- Go to Settings > Send Feedback
- Fill out the feedback form
- Attach screenshots if needed
- Submit

#### 2. Email
Send to: beta@grategenyen.com
- Subject: [BETA] Brief description
- Include all relevant details

#### 3. Beta Testing Form
Fill out our online form: [Link to form]

## Testing Scenarios

### Scenario 1: First-Time Buyer
1. Register as a new buyer
2. Browse ticket categories
3. Select a ticket to purchase
4. Add to cart
5. Proceed to checkout
6. Complete payment
7. View confirmation
8. Check "My Tickets"

### Scenario 2: Seller Registration
1. Select "Seller" during registration
2. Fill in required information
3. Upload ID photo
4. Submit for approval
5. Check approval status

### Scenario 3: QR Code Scanning
1. Login as seller or admin
2. Navigate to QR scanner
3. Scan a ticket QR code
4. Verify ticket details displayed
5. Confirm validity

### Scenario 4: Offline Mode
1. Use app with internet connection
2. View some tickets
3. Turn off internet
4. Navigate to "My Tickets"
5. Verify cached data displays
6. Attempt to purchase (should show error)
7. Turn on internet
8. Verify app syncs properly

## Beta Program Rules

1. **Confidentiality**: Don't share the beta app or screenshots publicly
2. **Active Participation**: Try to test at least 2-3 times per week
3. **Timely Feedback**: Report issues as you find them
4. **Respectful Communication**: Be constructive in your feedback
5. **Test Responsibly**: Don't use real payment credentials in test environment
