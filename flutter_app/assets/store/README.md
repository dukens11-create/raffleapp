# App Store Assets

This directory contains assets for app store submissions.

## Directory Structure

```
assets/store/
├── android/
│   ├── screenshots/
│   │   ├── phone/          # Phone screenshots (6-8 images)
│   │   └── tablet/         # Tablet screenshots (optional)
│   ├── feature_graphic.png # 1024 x 500 px
│   └── icon.png           # 512 x 512 px
├── ios/
│   ├── screenshots/
│   │   ├── 6.5-inch/      # iPhone 14 Pro Max, 15 Plus
│   │   ├── 6.7-inch/      # iPhone 14 Pro Max
│   │   └── 5.5-inch/      # iPhone 8 Plus
│   └── icon.png           # 1024 x 1024 px
└── promotional/
    ├── video.mp4          # App preview video (optional)
    └── promo_graphics/    # Marketing materials
```

## Requirements

### Google Play Store (Android)

#### Screenshots
- **Phone**: 2-8 screenshots
  - Dimensions: 16:9 or 9:16 aspect ratio
  - Minimum: 320px
  - Maximum: 3840px

#### Feature Graphic
- Dimensions: 1024 x 500 px
- Format: PNG or JPG

#### App Icon
- Dimensions: 512 x 512 px
- Format: 32-bit PNG

### Apple App Store (iOS)

#### Screenshots
Required for:
- **6.7-inch display**: 1290 x 2796 px
- **6.5-inch display**: 1284 x 2778 px
- **5.5-inch display**: 1242 x 2208 px

#### App Icon
- Dimensions: 1024 x 1024 px
- Format: PNG (no alpha channel)

## Asset Creation Instructions

Place your app store assets in the appropriate directories before submission.
