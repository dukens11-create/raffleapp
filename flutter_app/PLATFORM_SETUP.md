# Flutter Platform Files Setup

## Overview

The Android and iOS platform directories are typically generated by Flutter and excluded from version control. This document provides the necessary files and configuration to set up both platforms.

## Android Setup

### Required Files

The following Android files have been created in the `android/` directory:

#### 1. `android/settings.gradle`
Configures Gradle settings and Flutter plugin loader.

#### 2. `android/build.gradle`
Root-level Gradle build configuration.

#### 3. `android/gradle.properties`
Gradle properties including JVM arguments and AndroidX settings.

#### 4. `android/app/build.gradle`
App-level build configuration with:
- Application ID: `com.grategenyen.raffleapp`
- Min SDK: 21 (Android 5.0)
- Target SDK: 34 (Android 14)
- Version: 1.0.0 (code 1)
- ProGuard enabled for release builds
- MultiDex support

#### 5. `android/app/src/main/AndroidManifest.xml`
App manifest with:
- App name: "Grate Genyen"
- Required permissions: INTERNET, CAMERA, READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE
- Main activity configuration

#### 6. `android/app/src/main/kotlin/com/grategenyen/raffleapp/MainActivity.kt`
Main activity entry point in Kotlin.

#### 7. `android/app/proguard-rules.pro`
ProGuard rules for code obfuscation and optimization.

### Setup Instructions

Since these files are in `.gitignore`, you can either:

1. **Generate with Flutter CLI** (Recommended):
   ```bash
   cd flutter_app
   flutter create --platforms android,ios .
   ```
   Then apply the configurations from the templates above.

2. **Manual Setup**:
   Copy the files from the `android/` directory structure to your project.

### Building Android

```bash
# Debug APK
flutter build apk --debug

# Release APK
flutter build apk --release

# App Bundle (for Play Store)
flutter build appbundle --release
```

## iOS Setup

### Required Files

The following iOS files have been created in the `ios/` directory:

#### 1. `ios/Podfile`
CocoaPods configuration for iOS dependencies.

#### 2. `ios/Runner/Info.plist`
iOS app configuration with:
- Display Name: "Grate Genyen"
- Bundle Identifier: To be configured in Xcode
- Camera Usage Description
- Photo Library Usage Description
- Minimum iOS: 12.0

#### 3. `ios/Runner/AppDelegate.swift`
App delegate for iOS lifecycle management.

### Setup Instructions

1. **Generate with Flutter CLI** (Recommended):
   ```bash
   cd flutter_app
   flutter create --platforms android,ios .
   ```

2. **Install CocoaPods Dependencies**:
   ```bash
   cd ios
   pod install
   cd ..
   ```

3. **Configure Signing in Xcode**:
   ```bash
   open ios/Runner.xcworkspace
   ```
   - Select "Runner" project
   - Go to "Signing & Capabilities"
   - Select your development team
   - Configure bundle identifier

### Building iOS

**Note: Requires macOS with Xcode**

```bash
# Debug build
flutter build ios --debug

# Release build
flutter build ios --release

# IPA for distribution
flutter build ipa --release
```

## Platform Files Location

All platform configuration files are available in:
- `flutter_app/android/` - Android platform files
- `flutter_app/ios/` - iOS platform files

These directories are excluded from Git via `.gitignore` as they contain generated and platform-specific files.

## Initialization Command

To initialize both platforms at once:

```bash
cd flutter_app
flutter create --platforms android,ios .
```

This will create the necessary platform directories while preserving your existing Dart code.

## Verification

After setup, verify the configuration:

```bash
flutter doctor -v
flutter pub get
flutter analyze
```
